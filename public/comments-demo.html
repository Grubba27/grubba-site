Comments, styled by the forum

This page has no CSS for the comments below. Their colours, fonts and any extra rules come from the forum at forum.grubba.dev: change its colour palette or its theme's Embedded CSS and this page follows, no deploy needed. The blog post shows the same conversation painted in the site's own Windows 95 or brutalist skin instead.

All it takes:

<script type="module" src="https://cdn.jsdelivr.net/npm/g-comments/dist/element.js"></script>
<discourse-comments forum="https://forum.grubba.dev" theme="forum"></discourse-comments>

Left alone, the element uses the page's own URL as the thread. This one points at the blog post's thread so there is something to read: so far.
