Comments, styled by the forum

This page has no CSS for the comments below. Their colours, fonts and any extra rules come from the forum at forum.grubba.dev: change its colour palette or its theme's Embedded CSS and this page follows, no deploy needed. The blog post shows the same conversation painted in the site's own Windows 95 or brutalist skin.

All a page needs:

<script type="module" src="https://cdn.jsdelivr.net/npm/g-comments/dist/element.js"></script>
<discourse-comments forum="https://forum.grubba.dev" theme="forum"></discourse-comments>

Written like that, the element sends the page's own address (its canonical link, or the URL in the address bar) to the forum, which tidies it up, looks it up among the pages it already knows, and creates an unlisted topic for it on the first visit. The topic appears on the forum once someone comments. Nothing on the site keeps track of topics.

This page is the exception: it names the blog post's address so there is something to read, which is also how two pages can share one conversation. 

<discourse-comments
  forum="https://forum.grubba.dev"
  theme="forum"
  url="https://grubba.dev/blog/1433307"
></discourse-comments>
