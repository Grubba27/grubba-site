Comments, styled by the forum

This page has no CSS for the comments below. Their colours, fonts and any extra rules come from the forum at forum.grubba.dev: change its colour palette or its theme's Embedded CSS and this page follows, no deploy needed. The blog post shows the same conversation painted in the site's own Windows 95 or brutalist skin.

All a page needs:

<script type="module" src="https://cdn.jsdelivr.net/npm/g-comments/dist/element.js"></script>
<discourse-comments forum="https://forum.grubba.dev" theme="forum"></discourse-comments>

Written like that, the element sends the page's own address (its canonical link, or the URL in the address bar) to the forum, which tidies it up, looks it up among the pages it already knows, and creates an unlisted topic for it on the first visit. The topic appears on the forum once someone comments. Nothing on the site keeps track of topics.

This page is the exception: it names the blog post's address so there is something to read, which is also how two pages can share one conversation. 

<discourse-comments
  forum="https://forum.grubba.dev"
  theme="forum"
  url="https://grubba.dev/blog/1433307"
></discourse-comments>

Same thread as the blog post: so far.

Other ways to use it

The same package ships a React build, which is what the blog uses. One provider for the forum, then a component wherever comments belong; the stylesheet is optional. 

npm install g-comments
import { DiscourseComments, Comments, CommentCount } from "g-comments/react";
import "g-comments/styles.css";

<DiscourseComments forum="https://forum.grubba.dev" theme="forum">
  <Comments />                                    {/* this page's own address */}
  <Comments url="https://grubba.dev/blog/1433307" /> {/* a chosen thread */}
  <CommentCount url="https://grubba.dev/blog/1433307" />
</DiscourseComments>

To paint the comments yourself, set the --gc-* tokens in your CSS. Whatever the site sets wins over the forum's theme, which wins over the defaults, so a site can take the forum's look and override just a few things, as the blog's Windows 95 skin does. 

.gc-root {
  --gc-font: "MS Sans Serif", sans-serif;
  --gc-accent: #000e7a;
  --gc-radius: 0;
}

For a layout of your own, the hooks give you the data and the actions and the primitives give you the pieces: 

import { Comments, useCommenter, useThread } from "g-comments/react";

const { thread, snapshot } = useThread({ url, sort: "newest" });
// snapshot.comments, snapshot.count, thread.post({ body }), thread.like(id), thread.loadMore()

const me = useCommenter();
// me.user, me.status, me.providers, me.signIn({ provider: "github" })

<Comments.Root url={url} signIn="manual">
  <Comments.Header><Comments.Count /><Comments.Sort /></Comments.Header>
  <Comments.Composer />
  <Comments.List>
    {(comment, depth) => (
      <Comments.Item comment={comment} depth={depth}>
        <Comments.Avatar /><Comments.Body /><Comments.Actions />
      </Comments.Item>
    )}
  </Comments.List>
</Comments.Root>

The custom element takes the same options as attributes: identifier for a stable key of your own, sort, sign-in="inline|on-submit|manual", read-only, theme="auto|light|dark|inherit|forum", and <discourse-comment-count url="…"> for lists of posts.
