Make your own

  1. On a Discourse forum, install the discourse-comments plugin and allow your site's host under Admin → Customize → Embedding (or set discourse_comments_allowed_origins to * on a staging forum).
  2. On the page, add the two lines from the Code tab: the script and <discourse-comments forum="…">. With React, npm install g-comments and render <Comments /> inside <DiscourseComments forum="…">.
  3. That is it. Readers sign in through a popup on the forum, and each comment is a post in a topic the forum creates for the page, so replies, likes, moderation and the review queue are the forum's own.

Which page is this?

By default the element sends the page's URL: the <link rel="canonical"> if there is one, else the address bar. The forum normalises it (https, lowercase, no #fragment, no utm_* and other tracking params, no trailing slash), so /blog/1?utm_source=x#top and /blog/1 are one thread. It then finds the topic for that key or creates one, unlisted until the first comment. 

<!-- default: this page's URL -->
<discourse-comments forum="https://forum.grubba.dev"></discourse-comments>

<!-- stable key: survives slug or domain changes (unique per site host, up to 100 chars) -->
<discourse-comments forum="https://forum.grubba.dev" identifier="blog-1433307"></discourse-comments>

<!-- another page's thread, for mirrors or a "discussion" page -->
<discourse-comments forum="https://forum.grubba.dev" url="https://grubba.dev/blog/1433307"></discourse-comments>

In React the props are the same: <Comments identifier="blog-1433307" />. Adding an identifier to a page that already has comments is safe: it is linked to the topic its URL already found. Mirrors on other hosts share threads through the forum's host aliases setting; that is how brutalist.grubba.dev shows grubba.dev's comments. This page uses the url form.

Who styles what

Forum is the bare component: colours, fonts and the forum's own Embedded CSS (the accent bar) come from the forum. The other two add the site's --gc-* tokens on top. Site beats forum beats defaults. With the custom element, set tokens on ::part(gc-root); in React, on .gc-root.

Headless

Your own layout, same data:

import { Comments, useCommenter, useThread } from "g-comments/react";

const { thread, snapshot } = useThread({ url, sort: "newest" });
// snapshot.comments, snapshot.thread.count, thread.post({ body }), thread.like(id), thread.loadMore()

const me = useCommenter();
// me.user, me.status, me.providers, me.signIn({ provider: "github" })

<Comments.Root url={url} signIn="manual">
  <Comments.Header><Comments.Count /><Comments.Sort /></Comments.Header>
  <Comments.Composer />
  <Comments.List>
    {(comment, depth) => (
      <Comments.Item comment={comment} depth={depth}>
        <Comments.Avatar /><Comments.Body /><Comments.Actions />
      </Comments.Item>
    )}
  </Comments.List>
</Comments.Root>
